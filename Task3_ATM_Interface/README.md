# Task 3 - ATM Interface

## Overview
This project is a simple console-based ATM Interface built in Java. It simulates basic banking operations such as checking balance, depositing money, and withdrawing money using an interactive menu-driven system.

## Features
- Check account balance
- Deposit money into the account
- Withdraw money from the account (with insufficient balance handling)
- Simple and easy-to-use menu interface
- Exit option to close the application

## Technologies Used
- Java
- Scanner class for user input

## How It Works
The program uses two classes:

1. **BankAccount** - Handles the core banking logic, including storing the balance and performing deposit and withdrawal operations.
2. **ATM** - Manages the user interface, displaying the menu and handling user choices in a loop until the user selects the exit option.

## How to Run
1. Clone or download this repository.
2. Navigate to the `Task3_ATM_Interface` folder.
3. Compile the Java file: javac ATMinterface.java
4. Run the code java ATMinterface
